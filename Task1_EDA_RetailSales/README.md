# Task 1 - EDA on Retail Sales Data

## Objective
Perform exploratory data analysis on a retail sales dataset to uncover sales trends, customer demographics, and product performance, and provide business recommendations.

## Tools Used
Python, pandas, matplotlib, seaborn, Jupyter Notebook

## Dataset
Retail Sales Dataset (Kaggle) - 1000 transactions with customer demographics, product category, quantity, price, and total amount.

## Key Findings
1. Electronics and Clothing bring in almost the same revenue, both ahead of Beauty.
2. Sales peak in Q4 (Oct-Dec), suggesting the need for pre-season stocking and promotions.
3. Men spend less than women in the Clothing category specifically, unlike Beauty and Electronics where spending is close between genders.

## How to Run
1. Clone this repo
2. Open `EDA_Retail_Sales.ipynb` in Jupyter Notebook
3. Ensure `retail_sales_dataset.csv` is in the same folder
4. Run all cells
